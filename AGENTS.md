# Agent instructions

Single source of truth for **Cursor**, **Claude Code**, and other agents in this repo.

## Project

Next.js 16 marketing site (training, BIM Soft Solutions, contact, downloads). Dev server: port **3100**.

```bash
npm run dev          # local dev (port 3100)
npm run lint         # tsc --noEmit
npm run build        # production build
npm run check:env    # env var contract vs .env.example
npm run check:secrets
```

## Git & PR workflow

**Do not use `gh` (GitHub CLI).** It is not available. Use **git** only and give the user copy-paste commands plus the PR link.

### Commit (only when the user asks)

```bash
git status
git diff
git diff --cached
git log --oneline -5
```

Stage explicit paths, commit with HEREDOC message, then `git status`. Never commit `.env`, `.env.local`, or secrets. Skip `next-env.d.ts` unless the user asks — it is auto-generated by Next.js dev.

### Branch, push, open PR

```bash
git checkout -b feature/your-branch-name
git add <files>
git commit -m "$(cat <<'EOF'
Commit message.

EOF
)"
git push -u origin HEAD
```

Share this PR URL (never run `gh pr create`):

```
https://github.com/digibimhub/digibimhub/compare/main...<branch-name>?expand=1
```

Or the link git prints on first push:

```
https://github.com/digibimhub/digibimhub/pull/new/<branch-name>
```

Include a suggested PR title and body (Summary + Test plan) for the user to paste on GitHub.

### Safety

- Never update git config, force-push to `main`, or skip hooks unless explicitly requested.
- Do not push or commit unless the user asks.

## Conventions

- Minimize diff size; match existing Tailwind and component patterns.
- Product name: **BIM Soft Solutions** (`lib/software-solutions.ts` → `productName`).
- Branding: `BrandLockup` — header `variant="mark"` (icon on white panel); footer full lockup (icon + title + tagline). Logo mark is SVG via `LogoMark` / `public/logo-mark.svg` — no PNG mark.
- Contact email: Resend API; `CONTACT_TO_EMAIL` and `CONTACT_FROM_EMAIL` default to `info@digibimhub.com`; submitter email as `replyTo`.

## Gotchas

- `lint` is TypeScript check only (`tsc --noEmit`), not `next lint`.
- CI on PRs: build, lint, env contract, secret scan, dependency audit (Node 24).
